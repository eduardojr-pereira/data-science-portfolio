<a id="setup"></a>

## Setup and Installation

Clone the portfolio and navigate to the selected project:

```bash
git clone https://github.com/eduardojr-pereira/data-science-portfolio.git
cd data-science-portfolio/selected_projects/bike_sharing
python -m pip install -r requirements.txt
jupyter lab
```

Each project is responsible for its own setup instructions and dependencies. There is no repository-wide `requirements.txt`.

## Testing and Validation

## How to Use

Start with a project README to understand its objective and evidence. Open the notebook to inspect methods and calculations; use the interactive report when available; consult validation and limitations before reusing conclusions.

For Bike Sharing, open the [interactive report](https://eduardojr-pereira.github.io/data-science-portfolio/selected_projects/bike_sharing/reports/) or the [project documentation](./bike_sharing/README.md).
