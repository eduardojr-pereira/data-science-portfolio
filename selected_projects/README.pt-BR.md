<a id="setup"></a>

## Instalação e Configuração

Clone o portfólio e entre na pasta do projeto selecionado:

```bash
git clone https://github.com/eduardojr-pereira/data-science-portfolio.git
cd data-science-portfolio/selected_projects/bike_sharing
python -m pip install -r requirements.txt
jupyter lab
```

Cada projeto documenta seu ambiente e suas dependências. Não há um `requirements.txt` global no repositório.
