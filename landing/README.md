# Landing content

`content.json` owns bilingual editorial copy, approved About panels, selected-project evidence captions and displayed metrics, the CTA outline geometry, and explicit media references. The catalog and per-project `project.json` remain the only owners of project titles, descriptions, topics and technologies. The institutional hero lines derive from the canonical shared signature. The EP Brand builder owns page composition, theme, locale, navigation and shared UI behavior. The landing-specific layout and motion are maintained in EP Brand; no standalone preview HTML or runtime is retained here.

The media files are exact decoded bytes recovered from the approved Selected Projects 05 (12 SVG variants), About Me 04 (portrait), CTA 02 (video and poster), and Contact 07 (two registered textures). The Bike Sharing metric values were checked against the saved day/hour datasets without running notebooks. See `media-provenance.json` for hashes; extraction does not establish third-party publication rights. The source files must be reviewed before deployment. The local integration preview has no contact delivery endpoint, no named form fields and no actual legal policies; the publication plan belongs to Lote 11. Existing public report routes are retained until their approved migration.
